# Wyra Panel
Wyra Panel is a Free Open-Source (FOSS/libre) server management panel that includes (check TODO.md for more info) features such as:
- Real-time statistics
- Rich plugin support
- Connecting Nodes
- Support for multiple login providers (e.g. LDAP, SAML, OIDC, PAM, local, from plugins, etc.)
- Audit Logging

## AI Usage Policy:
Claw-based agents are allowed, **though they need to be specified in whatever they are trying to do.**
AI Helpers are allowed, though you can't vibe code. This doesn't mean to not comment your code, please add comments.
